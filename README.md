# Пепельный Дозор

Башенная оборона: тропа, башни, золото за убийства, волны и улучшения.

## Запуск у себя

Нужен [Node.js 22](https://nodejs.org/).

```bash
npm install
npm run dev
```

Откройте [http://localhost:8080](http://localhost:8080).

Сборка для выкладки: `npm run build`, затем `npm run preview`.
